Docker Exp 5

Packages the app and database into containers so it runs the same on any machine.

  • Dockerfile – builds the API image (node:20-alpine, non-root user, HEALTHCHECK)
  • docker-compose.yml – starts api + mongo together on one network
  • Volume mongo_data keeps tasks after restart
  • Run: docker compose up --build

Kubernetes Exp 7

Runs and manages the containers on a cluster – restarts them if they crash.

  • namespace.yaml – isolated space for the project
  • configmap.yaml / secret.yaml – settings & credentials
  • mongo-pvc.yaml – persistent storage for the DB
  • *-deployment.yaml – how many pods to run
  • *-service.yaml – stable network address for each pod

GitHub Actions CI/CD Exp 8

Runs automatically on every push to main (.github/workflows/ci-cd.yml):

  • 1. Test – npm test
  • 2. Docker build – builds the image
  • 3. Kubernetes test – deploys to a temporary kind cluster + smoke test
  • 4. Publish – pushes image to GitHub Container Registry

  • Tasks list – read, update status, delete
